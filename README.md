# Transform Fitness Hub

Crie uma landing page para um Personal Trainer, com visual moderno, forte e esportivo.

IDENTIDADE VISUAL:

- Paleta de cores: preto (#0D0D0D), branco e verde neon (#A8FF00) como cor de destaque

- Tipografia: fontes bold/condensadas para títulos (estilo impacto, tipo "Anton" ou "Bebas Neue"), fonte limpa para texto corrido

- Estilo: fitness, motivacional, alto contraste, fotos em preto e branco ou com tom escuro de academia

SEÇÃO HERO:

- Foto grande do personal trainer (uso a imagem anexada) ocupando o lado direito ou como fundo em tela cheia, com leve escurecimento/gradiente do lado esquerdo para dar legibilidade ao texto

- Título grande: "PERSONAL TRAINER"

- Subtítulo em verde neon: "RESULTADOS REAIS, TRANSFORMAÇÕES REAIS."

- Botão de call-to-action em destaque (verde neon, texto preto): "AGENDAR AVALIAÇÃO GRATUITA"

- Um pequeno indicativo de confiança abaixo do botão (ex: "+500 alunos transformados")

SEÇÃO SOBRE:

- Foto menor ou a mesma foto em outro enquadramento

- Texto curto contando a experiência, certificações e método de trabalho

- 3 números em destaque (anos de experiência, alunos atendidos, avaliação média)

SEÇÃO SERVIÇOS/PLANOS:

- 3 cards: Treino Presencial, Treino Online, Consultoria Nutricional (ou ajustar conforme o serviço real)

- Cada card com ícone, título, descrição curta e preço/botão "Saiba mais"

SEÇÃO DEPOIMENTOS:

- Carrossel ou grid com 3 depoimentos de alunos (nome, foto, frase curta, estrelas)

SEÇÃO ANTES/DEPOIMENTOS DE RESULTADOS:

- Grid de fotos de transformação (placeholder por enquanto)

SEÇÃO CONTATO/CTA FINAL:

- Fundo preto, título grande "PRONTO PARA COMEÇAR SUA TRANSFORMAÇÃO?"

- Botão verde neon grande levando para WhatsApp ou formulário de contato

- Ícones de redes sociais (Instagram, WhatsApp)

RODAPÉ:

- Logo/nome, links rápidos, redes sociais, direitos autorais

Responsivo para mobile, com a foto do hero se ajustando para não cortar o rosto. Animações sutis de fade-in ao rolar a página.
